# Excel 스케줄 관리 - 빠른 시작 가이드

**최신 버전**: 2026-02-06

## 🎯 5분 만에 시작하기

### Step 1: 샘플 다운로드
```
1. 시스템 로그인
2. 대시보드의 [📥 샘플 다운로드] 버튼 클릭
3. `FMS_Schedule_Template_YYYY-MM-DD.xlsx` 다운로드
```

### Step 2: Excel 파일 준비
```
다운로드한 샘플 파일을 열어서:
1. 데이터 추가 (필수 컬럼):
   - CALLSIGN: 항공기 콜사인 (예: AAR123)
   - DEPT: 출발 공항 (예: RKSS)
   - DEST: 도착 공항 (예: RKPC)
   - CFL: 순항 고도 (예: FL280)
   - EOBT: 예상 이륙 시간 UTC (예: 0630)
   - DAY_OF_WEEK: 요일 (1=월, 2=화, ..., 7=일)

2. 저장 (Ctrl+S)
```

### Step 3: 업로드
```
1. [📂 Excel 업로드] 클릭
2. 준비한 Excel 파일 선택
3. 기간 선택 모달:
   - [6개월] 버튼 클릭 (또는 날짜 직접 입력)
   - [확인] 클릭
4. 겹침 경고가 나타나면 [📤 업로드] 클릭
5. 성공 메시지 확인!
```

## ✅ 검증 (2분 테스트)

```bash
# 1. 기간 선택 모달 표시 확인
- [📂 Excel 업로드] 클릭
- 모달이 나타나는가? ✓

# 2. 빠른 선택 버튼 동작 확인
- [6개월] 클릭
- 날짜 필드가 6개월 범위로 설정되는가? ✓

# 3. 기간 요약 표시 확인
- "📅 YYYY-MM-DD ~ YYYY-MM-DD (약 6개월)" 표시되는가? ✓

# 4. 샘플 다운로드 동작 확인
- [📥 샘플 다운로드] 클릭
- Excel 파일이 다운로드되는가? ✓

# 5. 데이터 업로드 확인
- 샘플 파일로 업로드 시도
- "✅ {개수}개 항공편이 업로드되었습니다" 토스트 표시? ✓

# 6. 겹침 경고 확인
- 같은 기간으로 다시 업로드
- "⚠️ 기존 데이터 덮어쓰기 경고" 모달 표시? ✓

# 모든 ✓ 확인되면 완료!
```

## 🔑 주요 기능

| 기능 | 설명 |
|------|------|
| **📂 Excel 업로드** | 스케줄 데이터 업로드 |
| **📥 샘플 다운로드** | 올바른 형식의 샘플 파일 다운로드 |
| **🗓️ 기간 선택** | 스케줄 유효 기간 설정 (기본: 6개월) |

| **📤 부분 업로드** | 겹치는 기간만 업데이트 (전체 삭제 X) |
| **📊 필터링** | 선택한 날짜에 해당하는 항공편만 표시 |

## 💡 팁

### 기간 선택
```
매월 자동으로 업데이트하려면:
1. 시스템 날짜: 2026-02-06
2. 기간 선택: [6개월] → 2026-02-06 ~ 2026-08-06
3. 매달 1일경에 새로운 Excel 업로드
```

### 연간 스케줄
```
1월에 1년 치 데이터 업로드:
1. [1년] 버튼 클릭
2. 범위: 2026-01-01 ~ 2026-12-31
3. 전체 연간 스케줄 적용
```

### 부분 업데이트
```
4월 1일에 새로운 데이터 업로드:
1. 기존: 2026-02-06 ~ 2026-08-06
2. 새로운: 2026-04-01 ~ 2026-10-01
3. 결과:
   - 2월~3월: 기존 데이터 유지
   - 4월~8월: 새 데이터로 업데이트
   - 9월~10월: 새 데이터 추가
```

## 🐛 문제 해결

### Q: "Error processing file" 에러가 나타남
**A**:
1. Excel 파일이 손상되었는지 확인
2. 샘플 다운로드로 올바른 형식 확인
3. 브라우저 콘솔(F12)에서 에러 메시지 확인

### Q: 겹침 경고가 나타나지 않음
**A**:
1. 이전 기간 데이터가 없는 것일 수 있음
2. 이전 기간과 겹치는 부분이 없는지 확인

### Q: 데이터가 표시되지 않음
**A**:
1. 선택한 날짜의 요일에 해당하는 데이터가 있는지 확인
2. 스케줄 기간 내 날짜인지 확인 (기간 외 데이터는 표시 안 됨)
3. 캐시 지우기 (Ctrl+Shift+Delete)
