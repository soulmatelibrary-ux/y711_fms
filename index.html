CJU Flow Simulator 사용 가이드

시스템 소개

CJU Flow Simulator는 서해안 항공로(Y711)를 이용하여 제주(RKPC)로 향하는 항공편의 CTOT(Calculated Take-Off Time, 계산된 이륙시간)를 관리하는 시스템입니다.

여러 공항에서 출발한 항공기들이 동일한 항공로에서 합류할 때 안전한 분리 간격을 유지하도록 출발 시간을 자동으로 조정합니다.

대상 공항 및 합류 지점

공항 코드 합류지점 진입시간
김포 RKSS BULTI 8분
청주 RKTU MEKIL 7분
군산 RKJK MANGI 3분
광주 RKJJ DALSU 1분
항공로 경로:
BULTI → MEKIL → GONAX → BEDES → ELPOS → MANGI → DALSU → NULDI → DOTOL → 제주

CTOT 계산 원리

1단계: EOBT 기준

CTOT는 EOBT(예상 이륙 시간)보다 빠를 수 없습니다.

2단계: 이륙 간격 적용

같은 공항에서 연속 출발하는 항공기는 최소 이륙 간격을 유지합니다.

3단계: 웨이포인트 분리

합류 지점에서 앞 항공기와 최소 3분 분리를 유지하도록 CTOT를 조정합니다.

핵심 원칙: 각 웨이포인트에서 항공기 간 충돌(3분 미만 분리)이 발생하지 않도록 뒤따르는 항공기의 CTOT를 자동으로 지연시킵니다.

CTOT "+1" 표시 의미

CTOT 옆의 +1은 다음 날(+1일)을 의미합니다.

예시:

EOBT: 2340 (23:40)

CTOT: 0004+1 → 다음 날 00:04

자정(00:00)을 넘긴 CTOT는 다음 날로 표시되어, 운항일 혼동을 방지합니다.

웨이포인트 통과 시간 계산 예제

각 공항에서 이륙 후 합류 지점까지의 시간과 이후 웨이포인트 통과 시간이 계산됩니다.

예제 1: 김포(RKSS) 출발 항공기

CTOT: 0600 (06:00 이륙)

웨이포인트 통과 시간:

BULTI (합류) = 0600 + 8분 = 0608
MEKIL = 0608 + 2분 = 0610
GONAX = 0610 + 2분 = 0612
...
예제 2: 청주(RKTU) 출발 항공기

CTOT: 0603 (06:03 이륙)

웨이포인트 통과 시간:

MEKIL (합류) = 0603 + 7분 = 0610
GONAX = 0610 + 2분 = 0612
충돌 감지 및 CTOT 조정 예제

위 예제에서 김포 항공기와 청주 항공기가 MEKIL에서 동시 도착 (둘 다 0610)

문제: MEKIL 분리 = 0분 (3분 미만)

해결: 청주 항공기 CTOT를 3분 지연

새 CTOT: 0603 → 0606

→ MEKIL 도착: 0606 + 7분 = 0613 (김포와 3분 분리 확보)

사용 방법

1. 데이터 로드

상단의 Excel 버튼으로 스케줄 파일 업로드
(CALLSIGN, DEPT, DEST, CFL, EOBT_UTC, DAY_OF_WEEK 컬럼 필요)

2. CTOT 계산

Refresh CTOT 버튼 클릭 또는 항공편 순서 변경 시 자동 계산

3. 시뮬레이션

▶ 재생 버튼으로 시뮬레이션 시작
속도 조절: 1x, 2x, 5x, 10x, 20x

4. 설정 변경

Settings에서 진입 시간, 웨이포인트 구간 시간, 분리 기준 조정 가능
